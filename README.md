# Wholesale Customers - Machine Learning Project

## 1. Project Overview
This project explores the Wholesale Customers dataset
and applies basic machine learning algorithms
to classify customer segments.

## 2. Dataset
Source: Kaggle Wholesale Customers Dataset

## 3. Data Preprocessing
- Data inspection
- Missing value checking
- Feature selection
- Data normalization

## 4. Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## 5. Model Evaluation
Models are evaluated using accuracy
and cross-validation.

## 6. Results
The models are compared based on
their classification accuracy.

## 7. Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
